# Dotfiles
This reporistory contains a bunch of configurations for the tools I use.
## How to install/use
Clone repository
```
git clone https://github.com/vihaan211005/dotfiles
```
Stow the configs you need
```
cd dotfiles
stow <tool>
```
I also have added a script to change theme using CLI as well as rofi(config inside i3)
```
theme-switcher <theme>
```
